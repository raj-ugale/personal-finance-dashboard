# 💰 Personal Finance Dashboard

A modern and interactive finance tracking web app built with **React** and **Redux**.
It includes expense tracking, filters, editable transactions, PDF export, and a mock login system — perfect for a portfolio showcase.

## 🚀 Features
- Add, edit, and delete transactions
- Filter by date and category
- Export transactions to PDF
- Responsive, glassmorphic UI
- Mock authentication (Login & Register)

## 🛠️ Tech Stack
- React.js
- Redux Toolkit
- jsPDF + jsPDF-AutoTable
- Lucide React Icons
- CSS (modern glassmorphic design)
